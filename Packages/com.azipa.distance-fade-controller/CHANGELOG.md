# Changelog

## 0.1.0 (Beta)

- Renamed override section to Properties to Override; independent backface override preserves source W when disabled.
- Removed custom inspector title/version header; supported lilToon version is shown at the bottom.

- Connected prefab installation with Undo and duplicate prevention.
- Serialized distance fade overrides and bilingual inspector diagnostics.
- Inspector order and controls aligned with lilToon: numeric strength, backface checkbox, localized modes, HDR rim color, separate opacity, and power-3 sharpness slider.
- All, Exclude, Include Only object/renderer/material filters.
- Non-destructive NDMF material copies and virtual animation Material Swap processing.
- Explicit ordering after Modular Avatar, without a required MA dependency.
- VPM package metadata and Editor tests.
