# Installation / 導入

Target: Unity 2022.3.22f1 / VRChat PC Avatars SDK 3.x.

Install NDMF 1.11.0 or newer through VCC, then install lilToon (2.3.4 is the reference implementation).
Copy this package folder to `Packages/com.azipa.distance-fade-controller` for local installation.
Modular Avatar is optional.

For VPM distribution, upload a ZIP with package.json at its root, then publish a VPM repository entry with name, version, vpmDependencies, release URL, and SHA256. No hosted repository has been configured in this project.
Test assemblies are opt-in through the project manifest `testables` array.
